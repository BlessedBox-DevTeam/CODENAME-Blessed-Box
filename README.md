# 📦 CODENAME-BLESSED-BOX

Aplicación móvil con backend en tiempo real diseñada con **React Native (Expo)** y **Node.js + Express + Socket.IO**. Utiliza **MySQL** como base de datos.

---

## 📱 Frontend - Mobile App (`BlessedBoxApp/`)

### Tecnologías

- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [React Navigation](https://reactnavigation.org/)

### Iniciar el proyecto móvil

```bash
cd BlessedBoxApp
npm install
npx expo start
```
